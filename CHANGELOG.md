# Changelog

Each `## <version>` section becomes the notes of the matching GitHub release.

## 1.1.1 - 2026-11-17

- With no instrument selected, the plugin panel no longer opens as an empty box.

## 1.1 - 2026-11-17

- Mute: new item at the top of the right-click menu. Muting stops the plugin, so it uses no CPU, and keeps it loaded with its patch.
- Global hotkey and MIDI command to mute and unmute.
- New Shortcuts tab in Settings, with the show/hide and mute shortcuts.
- The menu bar icon now shows the app's state: muted, loading a plugin, or no plugin loaded.

## 1.0.1 - 2026-11-16

- The plugin panel comes to the front when opened by a shortcut.
- README: how to get past the Gatekeeper warning on first launch.

## 1.0 - 2026-11-16

- First release.
